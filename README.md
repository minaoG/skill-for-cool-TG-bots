# tg-premium-ui

**Skill для Claude Code и Claude.ai, который собирает Telegram-ботов на aiogram 3 в едином «дорогом» стиле — с премиум-эмодзи, цветными кнопками и готовым админ-каркасом.**

Перестань каждый раз объяснять нейросети, как должен выглядеть «красивый» бот. Один раз подключаешь скилл — и Claude знает твой стиль меню, твои паки премиум-эмодзи и обязательный набор админ-механик (статистика, ОП, бан, баланс, рекламные ссылки, рассылка). Просишь «сделай бота для X» — на выходе получаешь не сухой каркас, а живой продукт, готовый к деньгам.

---

## Зачем это нужно

Обычно при генерации Telegram-бота через ИИ приходится:

- объяснять, что меню должно быть на inline-кнопках, а не на «нижних» reply;
- вручную вставлять `icon_custom_emoji_id` и `<tg-emoji>` — и каждый раз искать ID;
- переписывать «ИИшные» канцелярские тексты на живые;
- с нуля городить админку: статистику, обязательную подписку, бан, рассылку;
- ловить баги вроде «база создалась не там» при запуске из cron/systemd.

Скилл закрывает всё это сразу. Claude получает **жёсткие правила стиля + рабочие шаблоны кода + готовый пак премиум-эмодзи с ID**, поэтому собранный бот выглядит дорого и единообразно, а не как очередная заготовка.

## Что внутри

### Премиум-стиль интерфейса
- Меню строго на `InlineKeyboardMarkup` — привязано к сообщению, перерисовывается через `edit_text`.
- Премиум-эмодзи двумя способами: иконка кнопки (`icon_custom_emoji_id`) и эмодзи в тексте (`<tg-emoji emoji-id="…">фолбэк</tg-emoji>`).
- Цветные кнопки через `style`: `success` (зелёная), `primary` (синяя), `danger` (красная) — дозированно, по одной акцентной кнопке на экран.
- «Живые» тексты вместо воды: обращение на «ты», подчёркивание выгоды через `<u>`, аккуратное форматирование (`<b>`, `<code>`, `<blockquote>`, `<tg-spoiler>`).
- Единая навигация: «Назад» всегда последним рядом, одна и та же иконка во всём боте.

### Два пака премиум-эмодзи с готовыми ID
Больше 60 иконок с фолбэками и колонкой «когда использовать» — заголовки, баланс, рефералы, бан, рассылка, статистика и т.д. Claude подбирает иконку по смыслу и вставляет ID литералом, без словарей и констант.

### Понятная архитектура
- Весь конфиг — наверху файла обычными переменными (токен, админы, цены, лимиты, тексты, флаги вкл/выкл). Никакого `.env` — всё меняется в одном месте.
- Все служебные файлы (БД, логи, выгрузки) строятся от `BASE_DIR` через `os.path.join` — бот работает одинаково из любой рабочей директории.
- Стек: **aiogram 3.x**, `ParseMode.HTML` глобально, SQLite (`aiosqlite`), состояния на FSM.

### Обязательный админ-каркас (готовые рабочие модули)
- **Подробная статистика** — пользователи (органика/рефералы), финансы в Stars и $, ARPU, конверсия, средний чек, динамика за час/сутки/неделю.
- **Обязательная подписка (ОП)** — гейт перед целевым действием, проверка подписки на каналы, управление каналами из админки.
- **Бан / разбан** — кэш в памяти + middleware, который глушит апдейты забаненных (админы под бан не попадают), уведомление пользователю с причиной.
- **Управление балансом** — абстрактная внутренняя валюта под любой бот (генерации, монеты, попытки), set/add/spend, ввод по ID или через reply-кнопку «Выбрать пользователя».
- **Рекламные ссылки с раздельной статистикой** — deep-link `?start=имя`, своя статистика по каждой когорте (клики, уники, новые, регистрации, оплаты).
- **Рассылка** — фото + текст + опциональная URL-кнопка через `copy_message` с превью, подтверждением и троттлингом против flood.

## Установка

### Для Claude Code

**На уровне проекта** (скилл доступен только в этом репозитории):
```bash
mkdir -p .claude/skills
cp -r tg-premium-ui .claude/skills/
```

**На уровне пользователя** (скилл доступен во всех проектах):
```bash
mkdir -p ~/.claude/skills
cp -r tg-premium-ui ~/.claude/skills/
```

Структура должна быть такой:
```
.claude/skills/tg-premium-ui/
└── SKILL.md
```

### Для Claude.ai
Загрузи `SKILL.md` в настройках возможностей (Capabilities) или приложи к чату — Claude подхватит правила автоматически.

## Как пользоваться

Подключив скилл, просто описывай задачу обычными словами:

> «Сделай бота-генератор юзернеймов: магазин за Stars, рефералка, обязательная подписка на 2 канала и полная админка.»

Claude сам:
1. вынесет конфиг наверх файла переменными;
2. построит меню на inline-кнопках с премиум-эмодзи из паков;
3. напишет живые тексты с подчёркиванием выгоды;
4. развернёт схему БД и все обязательные админ-функции;
5. соберёт рабочий однофайловый бот, готовый к запуску.

---

## Чеклист соответствия стилю

Каждый собранный по скиллу бот проходит проверку:

- [ ] Весь конфиг наверху файла, без `.env`;
- [ ] Служебные файлы — от `BASE_DIR` через `os.path.join`;
- [ ] Меню только на `InlineKeyboardMarkup`;
- [ ] `parse_mode=HTML` в `DefaultBotProperties`;
- [ ] Премиум-эмодзи только из паков, литералом;
- [ ] `style` — на одной важной кнопке экрана;
- [ ] Ключевые слова подчёркнуты `<u>`, тексты живые;
- [ ] Есть все обязательные админ-функции;
- [ ] Рассылка через `copy_message` + троттлинг;
- [ ] Забаненные глушатся middleware.

## Требования

- Python 3.10+
- aiogram 3.x
- aiosqlite

## Важно про премиум-эмодзи

Премиум-эмодзи отрисуются у всех пользователей **только если у бота есть к ним доступ**. Иначе покажется обычный эмодзи-фолбэк — поэтому фолбэки в скилле подобраны осмысленно. ID в паках — из конкретных наборов; не подставляй в бота чужие ID.
